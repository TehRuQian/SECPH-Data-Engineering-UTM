# 🎓 Year 2 Semester 2 (SECPH) Projects

This repository contains projects and coursework completed during **Year 2 Semester 2 (SECPH)**. The subjects focus on programming, data science, data mining, operating systems, and technology entrepreneurship, providing a strong foundation in both technical and professional skills.

## 📊 [Data Analytics Programming](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem2/Data%20Analytics%20Programming)
This course explores open-source programming for data science, with a strong focus on Python. Topics include programming fundamentals, data manipulation, statistical analysis, machine learning techniques, and effective data visualization to support data-driven decision-making.

## ⛏️ [Data Mining](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem2/Data%20Mining)
This course introduces the knowledge discovery process in databases and explores key data mining concepts, techniques, and algorithms. Students learn how to extract meaningful patterns from data and apply analytical methods to solve real-world business and industry problems.

## ☕ [Object-Oriented Programming](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem2/Object%20Oriented%20Programming)
This course introduces object-oriented programming concepts using Java. Topics include Java fundamentals, object-oriented design principles, standard APIs, exception handling, file I/O, and graphical user interface (GUI) development. Students develop structured and maintainable applications using object-oriented techniques.

## 💻 [Operating System](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem2/Operating%20System)
This course covers the fundamental concepts of operating systems and their role in managing computer resources. Topics include process management, memory management, file systems, concurrency, deadlock handling, scheduling algorithms, and input/output operations, providing insight into the design and implementation of modern operating systems.

## 🚀 [Technopreneurship Seminar](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem2/Technoprenuership%20Seminar)
This course provides hands-on experience in planning and managing a technology entrepreneurship seminar. Students collaborate to organize professional events by coordinating logistics, engaging industry speakers, promoting activities, and managing on-site operations, while developing leadership, teamwork, communication, and project management skills.
