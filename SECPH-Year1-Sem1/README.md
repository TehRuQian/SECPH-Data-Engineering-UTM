# 🎓 Year 1 Semester 1 (SECPH) Projects

This repository contains projects and coursework completed during **Year 1 Semester 1 (SECPH)**. The subjects introduce fundamental concepts in computing, programming, mathematics, digital systems, and information technology, forming the core foundation for future studies in computer science and software engineering.

## 🔌 [Digital Logic](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem1/Digital%20Logic)
This course introduces the fundamentals of digital electronics used in microprocessor-based systems such as computers, robotics, automotive systems, and industrial controllers. It covers core concepts including logic gates, digital circuits, and programmable logic devices, supported by hands-on laboratory experiments using simulators and real hardware.

## ➗ [Discrete Structure](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem1/Discrete%20Structure)
This course introduces mathematical structures used in computer science, including set theory, relations, functions, recurrence relations, counting techniques, graph theory, trees, and finite automata. Students learn to model computational problems using deterministic finite automata, apply graph theory to real-world problems, and solve problems using mathematical reasoning and proof techniques.

## 🛡️ [Integrity and Anti-Corruption](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem1/Integrity%20and%20Anti-Corruption)
This course focuses on ethics, integrity, and values based on the principles of Integrity, Synergy, Excellence, and Sustainability (ISES). It emphasizes the importance of ethical behavior, self-identity, and accountability in preventing corruption and misuse of power in both personal and organizational contexts.

## 💻 [Programming Technique I](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem1/Programming%20Technique%201)
This course provides foundational training in structured programming using C++. It covers basic programming concepts such as variables, data types, input/output operations, control structures (sequence, selection, and loops), functions, pointers, file operations, and user-defined data types to solve simple to moderate programming problems.

## 🌐 [Technology and Information System](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem1/Technology%20and%20Information%20System)
This introductory course explores the fundamentals of information systems and technology (IS/IT) in both personal and organizational contexts. It covers hardware, software, networking, and communication systems, with hands-on lab sessions involving PC installation and productivity tools. The course also includes seminars, industry visits, and exposure to real-world IT environments.
