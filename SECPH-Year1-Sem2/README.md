# 🎓 Year 1 Semester 2 (SECPH) Projects

This repository contains projects and coursework completed during **Year 1 Semester 2 (SECPH)**. The subjects build foundational knowledge in programming, system design, computer architecture, user experience, and statistical analysis, forming the basis for later advanced computing topics.

## 🖥️ [Computer Organization and Architecture](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem2/Computer%20Organization%20and%20Architecture)
This course explores the fundamentals of computer systems, including performance analysis, data representation, arithmetic operations, instruction execution, pipelining, memory hierarchy, I/O systems, and instruction formats. It provides a foundational understanding of hardware components and modern computer architecture.

## 👥 [Human Computer Interaction](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem2/Human%20Computer%20Interaction)
This course introduces human-computer interaction principles with a strong focus on user experience (UX) design. It emphasizes an iterative UX lifecycle involving contextual inquiry, requirements gathering, ideation, prototyping, and usability evaluation to create effective and user-friendly systems.

## 📊[Probability and Statistical Data Analysis](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem2/Probability%20and%20Statistical%20Data%20Analysis)
This course introduces statistical techniques for data analysis, covering data types, data visualization, parameter estimation, hypothesis testing, and model fitting. Students apply statistical methods using software tools to extract meaningful insights from real-world and industrial datasets.

## 💻 [Programming Technique II](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem2/Programming%20Technique%20II)
This course introduces object-oriented programming (OOP) using C++. It focuses on core concepts such as encapsulation, inheritance, polymorphism, and association, with an emphasis on solving computational problems using structured OOP design principles.

## 🧩 [System Analysis and Design](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year1-Sem2/System%20Analysis%20and%20Design)
This course provides hands-on experience in system analysis and design using both structured and object-oriented methodologies. It covers planning, requirements analysis, system design, and implementation phases, leading to the development of system models and prototype interfaces for organizational applications.
