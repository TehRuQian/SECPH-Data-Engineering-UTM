# 🎓 Year 2 Semester 1 (SECPH) Projects

This repository contains projects and coursework completed during **Year 2 Semester 1 (SECPH)**. The subjects focus on software development, databases, networking, system architecture, and algorithmic problem-solving, providing a strong foundation in computer science and software engineering principles.

## 🧩[ Data Structures and Algorithms](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem1/Data%20Structures%20and%20Algorithms)
This course covers both the theoretical and practical aspects of data structures and algorithm design. Topics include abstract data types, recursion, algorithm analysis using Big O notation, sorting and searching techniques, as well as the implementation of linear and non-linear data structures such as linked lists, stacks, queues, trees, and binary search trees through programming assignments and group projects.

## 🗄️ [Database](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem1/Database)
This course introduces fundamental database concepts and their applications in real-world systems. Students learn database design techniques, including entity-relationship (ER) modeling, normalization, SQL, and database management using DBMS tools. The course culminates in the development of a database application for a real-world organization.

## 🌐 [Network Communications](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem1/Network%20Communications)
This course provides an introduction to computer networking and data communication using a top-down approach based on the TCP/IP model. Topics include network architectures, communication protocols, internet technologies, and practical networking concepts that explain how modern networks operate and support digital communication.

## 🛠️ [Software Engineering](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem1/Software%20Engineering)
This course introduces an engineering-based approach to developing high-quality software systems. It covers software development life cycles, process models, requirements analysis, system design, testing, and maintenance. Students gain hands-on experience with object-oriented analysis and design using UML to produce essential software engineering artifacts and documentation.

## ⚙️ [System Development Technology](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year2-Sem1/System%20Development%20Technology)
This course introduces the technologies, methodologies, and tools used in modern system development. Topics include system architecture, software development frameworks, development methodologies, and deployment strategies. The course focuses on building practical skills for designing, developing, and maintaining scalable software solutions.
