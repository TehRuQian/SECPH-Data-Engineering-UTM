# 🎓 Year 3 Semester 2 (SECPH) Projects

This repository contains projects and coursework completed during **Year 3 Semester 2 (SECPH)**. The subjects focus on application development, business intelligence, entrepreneurship, data processing, and data engineering, providing both theoretical knowledge and practical industry-oriented experience.

## 📱 [Application Development](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year3-Sem2/Application%20Development)
A collection of Flutter-based projects developed throughout the course. Topics include Flutter fundamentals, CRUD applications, state management, local storage, REST API integration, Firebase/Supabase backend services, image uploads, push notifications, and mobile/web deployment.

## 📊 [Business Intelligence](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year3-Sem2/Business%20Intelligence)
This course covers the fundamentals of business intelligence, including data warehousing, ETL processes, dashboard design, and predictive analytics. Projects utilize industry-standard tools such as Tableau, Power BI, and Alteryx to transform raw data into actionable insights and support data-driven decision-making.

## 🚀 [Entrepreneurship and Innovation](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year3-Sem2/Entrepreneurship%20and%20Innovation)
Focused on developing an entrepreneurial mindset, creativity, and innovation in an AI-driven environment. The course explores opportunity recognition, business model design, AI-assisted ideation, prototyping, and venture development while emphasizing ethical and collaborative innovation.

## ⚡ [High Performance Data Processing](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year3-Sem2/High%20Performance%20Data%20Processing)
This course introduces cloud computing, high-performance computing (HPC), distributed systems, and large-scale data processing technologies. Projects demonstrate how these technologies support big data analytics, artificial intelligence, and scalable data-intensive applications.

## 🔧 [Special Topics in Data Engineering](https://github.com/TehRuQian/SECPH-Data-Engineering-UTM/tree/main/SECPH-Year3-Sem2/Special%20Topic%20In%20Data%20Engineering)
This course explores modern data engineering practices, emerging technologies, and current industry trends. Through hands-on projects, laboratory exercises, industry talks, and site visits, students gain practical experience in designing and managing large-scale data systems while connecting academic concepts with real-world applications.
