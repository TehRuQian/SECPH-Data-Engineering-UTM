# Instrumentation & Measurement
This course focuses on electrical measurement principles, instruments, and sensor technologies used to measure and analyze electrical parameters accurately. It combines theoretical knowledge with practical laboratory work to develop skills in instrument selection, error analysis, uncertainty estimation, and data processing. Overall, the course prepares students to apply precise measurement techniques for engineering problem-solving and decision-making.
