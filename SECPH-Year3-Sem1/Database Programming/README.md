# Database Programming
This course focuses on database programming concepts using both relational and non-relational database systems. It covers fundamental and advanced SQL topics such as queries, joins, aggregation, normalization, and database management before introducing MongoDB concepts including document-based storage, CRUD operations, and NoSQL database design. The course emphasizes practical database development and data handling techniques for modern applications.

## Assignment 1
This assignment focuses on designing and developing a hostel management database system using SQL to manage room allocations, student records, payments, and maintenance activities. It covers database creation, integrity constraints, data manipulation, filtering queries, reporting, aggregation functions, and view creation to support efficient hostel operations and analytical reporting. The assignment emphasizes practical database programming skills through the implementation of relational database concepts and real-world query operations.

## Project 1 - Car Rental System (MySQL)
The Car Rental System is a MySQL database project developed to demonstrate backend database operations using SQL. The project applies SQL concepts including DDL, DML, and DQL statements, along with joins, subqueries, aggregation, filtering, functions, and indexing techniques for query optimization. It manages customer, vehicle, reservation, payment, and employee data in a structured database system without requiring a front-end interface.
