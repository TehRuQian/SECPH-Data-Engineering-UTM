# Database Programming
This course focuses on database programming concepts using both relational and non-relational database systems. It covers fundamental and advanced SQL topics such as queries, joins, aggregation, normalization, and database management before introducing MongoDB concepts including document-based storage, CRUD operations, and NoSQL database design. The course emphasizes practical database development and data handling techniques for modern applications.

It covers database creation, integrity constraints, data manipulation, filtering queries, reporting, aggregation functions, and view creation to support efficient hostel operations and analytical reporting. The assignment emphasizes practical database programming skills through the implementation of relational database concepts and real-world query operations.
