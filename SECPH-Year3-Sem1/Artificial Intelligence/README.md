# Artificial Intelligence
This course focuses on the fundamental concepts and theories of Artificial Intelligence (AI), including data processing, algorithm implementation, and machine learning techniques. It emphasizes both theoretical and practical aspects of search algorithms, knowledge representation, and AI model development through hands-on assignments and collaborative projects.

## Project  
Rydit: Learn Mandarin is an AI-powered mobile application designed to help learners improve Chinese character writing through real-time handwriting recognition, adaptive learning, and gamified lessons. The app analyses stroke order, direction, and writing accuracy while using spaced repetition and personalized feedback to strengthen memory retention and maintain user engagement. By combining AI-driven guidance with interactive challenges, Rydit provides a more effective and enjoyable Mandarin learning experience.
